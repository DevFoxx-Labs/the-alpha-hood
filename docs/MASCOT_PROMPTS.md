## 0. How fashion brands use a mascot (read first)
A mascot can make a fashion brand look cheap if it's everywhere. The rule used by streetwear brands:
- **Product photography stays the hero.** On the homepage hero, product listing and product pages, real models and real garments lead.
- **The mascot owns the moments in between:** welcome, empty states, the size guide, order success, loading, the Alpha Club, social media humour, merch, packaging, stickers and drop announcements.
- **Keep it premium:** the same outfit language as your collection (black hoodie, cargos, clean sneakers), editorial lighting, a calm alpha attitude. No silly faces on the main brand surfaces.
- **One character, one look:** same face, fur colours, eye colour, hood shape and tag in every image. Seasonal outfits are fine, but the face never changes.

## 1. Setup: do this once (in ONE ChatGPT chat)
1. Generate the mascot with the master prompt you already have (wolf in a black hoodie, hood up).
2. Pick the best image and ask for a **character sheet**:
```
Using exactly this character, create a character reference sheet: front, 3/4, side and back full-body views,
plus 4 head close-ups (neutral, confident smirk, laughing, surprised). Same proportions, same fur colours,
same amber-yellow eyes, same black hoodie with hood up and ears through the slits, same small red side tag,
same black cargos and white sneakers. Plain light grey background, no text.
```
3. Keep that chat. For every new image: upload the character sheet and start the prompt with the **CHARACTER LOCK** below.

### CHARACTER LOCK (paste at the start of every prompt)
```
Use EXACTLY the same character "ALPHA" from the attached reference sheet: anthropomorphic grey wolf, lean athletic build,
charcoal and silver-grey stylised fur, white muzzle and chest, amber-yellow eyes, calm confident expression,
heavyweight oversized matte black hoodie with the hood up (ears through two slits), small red #E4002B woven side tag,
black cargo pants, chunky white low-top sneakers, thin silver chain. Premium stylised 3D render, fashion-campaign
lighting with rim light, realistic fabric texture. Do not change the face, colours or proportions.
```

### CUT-OUT ENDING (for transparent PNG cut-outs)
```
Full body, centered, transparent background (PNG), soft contact shadow under the feet only, no text, no logos, 4:5.
```
If transparency fails, ask for a "plain pure white background" and remove it with remove.bg/Photoroom.

## 8. Export checklist
- **Cut-outs:** PNG with transparency, 2000 px tall, plus WebP versions for the web (≤ 150 KB). File names like `alpha-01-hero-stance.png`.
- **Scenes and posters:** desktop 16:7 and mobile 4:5 crops; leave text space empty and add headlines in Canva/Figma using Anton.
- **Consistency check:** put all images side by side. If a face, eye colour or hood shape differs, regenerate it with the character sheet attached.
- **Legal:** AI images have unclear copyright. For the final official mascot, get a designer/3D artist to recreate the chosen character (owned files + trademark), then use AI only for variations.
- **Honesty:** merch mockups are previews. Shoot the real merch before selling it, and never use AI images as product photos or customer reviews.
