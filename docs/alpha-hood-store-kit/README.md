# The Alpha Hood — e-commerce development kit

| File | What it is |
|---|---|
| `PRD.md` | Full product requirements: reference analysis, platform options, every storefront/admin module with IDs & acceptance criteria, legal (India), architecture, integrations, milestones M0–M10, launch checklist |
| `FEATURE_LIST.md` | All 64 features at a glance (reference pattern vs extras, by phase) |
| `DESIGN.md` | UI spec: brand, tokens, typography, components, every screen, photography rules |
| `GRAPHICS_PROMPTS.md` | AI prompts for campaign moods, banners, tiles, icons, social, packaging, logo + real photoshoot shot list |
| `reference/*.png` | Screens: homepage, category listing, product page, checkout, mobile |
| `reference/prototype/` | HTML/CSS prototypes of those screens |

**Start in Claude Code (VS Code):** copy this kit into an empty project folder, decide the platform (PRD §4), then paste the quick-start prompt from `DESIGN.md` §0. Run each milestone with the prompt in `PRD.md` §12, one at a time.
